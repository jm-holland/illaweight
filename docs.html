Prise en main

Installation

Le framework se télécharge depuis GitHub. Clonez le dépôt, puis construisez les fichiers avec npm run build:lib ; ou liez directement le fichier via CDN sans rien installer :

Le paquet expose le CSS compilé (illaWeightCss(.min).css), les modules JS du framework et les polices en chemins relatifs : rien d'autre à copier dans votre projet. 

            
git clone https://github.com/jm-holland/illaweight.git
cd illaweight
npm install && npm run build:lib
Intégration du CSS

Avec un bundler (Vite, esbuild...), importez le point d'entrée du paquet. Sur une page statique, une seule balise link suffit : 

            
// main.js (depuis les sources locales / bundler)
// import "./illaWeightCss.css";

// page statique (CDN GitHub)
<link rel="stylesheet"
      href="https://cdn.jsdelivr.net/gh/jm-holland/illaweight@main/illaWeightCss.min.css"/>
Interactions optionnelles

La modale, les onglets et l'accordéon s'activent par un import du module d'interactions (détails dans la doc JS) : 

            
// import "./js/interactions.js";  (depuis les sources locales)
Mode sombre

Ajoutez l'attribut <html data-theme="light"> (la valeur "dark" active le thème sombre). Le script themeSwitch.js gère le commutateur et la persistance dans localStorage : 

            
<html lang="fr" data-theme="light">
Contribuer depuis les sources

Le dépôt git contient le point d'entrée Sass et ce site de documentation :

Structure du dépôt
            
git clone https://github.com/jm-holland/illaweight.git
cd illaweight
npm install && npm run build:lib

src/sass/main.scss      <- point d'entrée (normalize, base, utilities, grid, layout)
src/sass/base/          <- typo, grille, utilitaires responsive
src/sass/components/    <- buttons, card, form, table, modal, tabs, accordion...
src/sass/layout/        <- navigation, footer, layout, normalize
js/                     <- scripts (menu burger, mode sombre, alerte, modale, onglets, accordéon...)

Barre de navigation

La barre de navigation est le premier composant du framework : marque, liens à plat, sous-menus dépliants (survol ou clic épinglé), interrupteur mode sombre et menu burger responsive. Voir la barre réelle en haut de chaque page. Code HTML structurel : 

        
/** === Barre de navigation === */
<nav class="navigation" aria-label="Navigation">
  <div class="brand">
    <a href="/" title="Aller à la page d'accueil">
      <img src="/image.png" alt="logo de la marque" />
    </a>
  </div>
  /** Menu hamburger */
  <input class="menu-hamburger" type="checkbox" id="menu-hamburger" aria-label="Ouvrir le menu"/>
  <label class="menu-icon" for="menu-hamburger">
    <span class="hamburger-icon" aria-hidden="true"></span>
  </label>
  /** Menu principal */
  <ul class="menu">
    <li><a href="#typography">Typographie</a></li>
    <li><a href="#blockquote">Citation</a></li>
    <li><a href="#buttons">Boutons</a></li>
    <li>
      <a href="#" aria-label="sous-menu">Javascript</a>
        <ul>
          <li><a href="#darkMode">Mode sombre</a></li>
        </ul>
    <li>    
    /** Interrupteur mode sombre */
      <input type="checkbox" class="checkbox" id="themeSwitch" aria-label="Mode sombre"/>
        <label for="themeSwitch" class="checkbox-label">
          <span class="moon" title="Sombre">☽</span>
          <span class="sun" title="Clair">✷</span>
          <span class="ball" title="Mode sombre"></span>
        </label>
      <script type="module" src="/js/themeSwitch.js"></script>
    </li>
  </ul>
</nav>

Espacement

illaWeight CSS propose un large ensemble de classes utilitaires responsive de marge et de padding, en notation condensée, pour ajuster l'espacement d'un élément.
Marges et padding

Attribuez des valeurs de marge ou de padding responsive à un élément, ou à un seul de ses côtés, grâce aux classes condensées. Chaque propriété, toutes les propriétés à la fois et les axes vertical et horizontal sont couverts. Les classes s'appuient sur une map Sass par défaut allant de 1em à 7em.

Notations

  • m- pour les classes qui définissent la marge.
  • p- pour les classes qui définissent le padding.
  • mt- / pt- pour la marge ou le padding du haut.
  • mb- / pb- pour la marge ou le padding du bas.
  • ml- / pl- pour la marge ou le padding de gauche.
  • mr- / pr- pour la marge ou le padding de droite.

Où la taille va de 1 à 7. Des variantes responsive mobile-first existent par breakpoint : .mt-md-3, .px-sm-2, .my-lg-1…

Exemples :

            
.mt-1{
  margin-top : 1em;
}
.pl-3{
  padding-left:3em;
}

Grille responsive

Grille 12 colonnes mobile-first : container .grid + colonnes col-*. Les classes responsive ne s'appliquent qu'au-dessus de leur point de rupture : sm ≥ 48rem, md ≥ 64rem, lg ≥ 75rem.

Couleurs & accessibilité

Palette conforme WCAG 2.1 AA : texte ≥ 4.5:1, composants ≥ 3:1, vérifiée par audit automatisé en clair et en sombre. Deux familles de variables :

  • Teintes « texte » — thématisées (sombres en clair, claires en sombre) : --color-primary, --color-success, --color-danger, --color-error, --color-link et dérivés. Le suffixe -focus désigne le survol et le focus : plus sombre en clair, plus clair en sombre.
  • Solides constants — fonds à texte blanc garanti ≥ 4.5:1 quel que soit le thème : --color-primary-solid, --color-success-solid, --color-warning-solid, --color-error-solid, --color-muted-solid, --color-secondary.
