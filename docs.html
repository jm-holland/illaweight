Getting started

Installation

Le framework se telecharge depuis GitHub. Clonez le depot, puis construisez les fichiers avec npm run build:lib ; ou liez directement le fichier via CDN sans rien installer :

Le paquet expose le CSS compile (illaWeightCss(.min).css), les modules JS du framework et les polices en chemins relatifs : rien d'autre a copier dans votre projet. 

            
git clone https://github.com/jm-holland/illaweight.git
cd illaweight
npm install && npm run build:lib
Intégration du CSS

Avec un bundler (Vite, esbuild...), importez le point d'entree du paquet. Sur une page statique, une seule balise link suffit : 

            
// main.js (depuis les sources locales / bundler)
// import "./illaWeightCss.css";

// page statique (CDN GitHub)
<link rel="stylesheet"
      href="https://cdn.jsdelivr.net/gh/jm-holland/illaweight@main/illaWeightCss.min.css"/>
Interactions optionnelles

Modal, tabs et accordion s'activent par un import du module d'interactions (details dans la doc JS) : 

            
// import "./js/interactions.js";  (depuis les sources locales)
Dark Mode

Ajoutez l'attribut <html data-theme="light"> (la valeur "dark" active le theme sombre). Le script themeSwitch.js gere le commutateur et la persistance dans localStorage : 

            
<html lang="fr" data-theme="light">
Contribuer depuis les sources

Le depôt git contient le point d'entree Sass et ce site de documentation :

Structure du depôt
            
git clone https://github.com/jm-holland/illaweight.git
cd illaweight
npm install && npm run build:lib

src/sass/main.scss      <- point d'entree (normalize, base, utilities, grid, layout)
src/sass/base/          <- typo, grille, utilitaires responsive
src/sass/components/    <- buttons, card, form, table, modal, tabs, accordion...
src/sass/layout/        <- navigation, footer, layout, normalize
js/                     <- scripts (menu burger, dark mode, alert, modal, tabs, accordion...)

Barre de navigation

La barre de navigation est le premier composant du framework : marque, liens a plat, sous-menus depliants (survol ou clic epingle), interrupteur dark mode et menu burger responsive. Voir la barre reelle en haut de chaque page. Code HTML structurel : 

        
/** === Navigation bar === */
<nav class="navigation" aria-label="navigation">
  <div class="brand">
    <a href="/" title="Aller à la page d'accueil">
      <img src="/image.png" alt="logo de la marque" />
    </a>
  </div>
  /** Menu hamburger */
  <input class="menu-hamburger" type="checkbox" id="menu-hamburger" aria-label="Open the menu"/>
  <label class="menu-icon" for="menu-hamburger">
    <span class="hamburger-icon" aria-hidden="true"></span>
  </label>
  /** Menu principal */
  <ul class="menu">
    <li><a href="#typography">Typography</a></li>
    <li><a href="#blockquote">Blockquote</a></li>
    <li><a href="#buttons">Buttons</a></li>
    <li>
      <a href="#" aria-label="submenu">Javascript</a>
        <ul>
          <li><a href="#darkMode">Dark Mode</a></li>
        </ul>
    <li>    
    /** Dark Mode switch */
      <input type="checkbox" class="checkbox" id="themeSwitch" aria-label="Dark Mode"/>
        <label for="themeSwitch" class="checkbox-label">
          <span class="moon" title="Dark">☽</span>
          <span class="sun" title="light">✷</span>
          <span class="ball" title="Dark mode"></span>
        </label>
      <script type="module" src="/js/themeSwitch.js">alt;/script>
    </li>
  </ul>
</nav>

Spacing

illawebWeight CSS includes a wide range of shorthand responsive margin, padding utility classes to modify an element's apparence.
Margin and padding

Assign responsive-friendly margin or padding values to an element or a subset of its sides with shorthand classes. Includes support for individual properties, all properties, and vertical and horizontal properties. Classes are built from a default Sass map ranging from 1em to 7em.

Notations

  • m- for classes that set margin.
  • p- for classes that set padding.
  • mt- / pt- for classe that set margin or padding top
  • mb- / pb- for classe that set margin or padding bottom
  • ml- / pl- for classe that set margin or padding left
  • mr- / pr- for classe that set margin or padding right

Where size is 1 to 7. Des variantes responsive mobile-first existent par breakpoint : .mt-md-3, .px-sm-2, .my-lg-1…

exemples :

            
.mt-1{
  margin-top : 1em;
}
.pl-3{
  padding-left:3em;
}

Couleurs & accessibilité

Palette conforme WCAG 2.1 AA : texte ≥ 4.5:1, composants ≥ 3:1, vérifiée par audit automatisé en light et en dark. Deux familles de variables :

  • Teintes « texte » — thématisées (sombres en light, claires en dark) : --color-primary, --color-success, --color-danger, --color-error, --color-link et dérivés. Le suffixe -focus désigne hover/focus : plus sombre en light, plus clair en dark.
