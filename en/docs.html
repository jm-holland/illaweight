Getting started

Installation

The framework is downloaded from GitHub. Clone the repository, then build the files with npm run build:lib; or link the file directly via CDN without installing anything:

The package exposes the compiled CSS (illaWeightCss(.min).css), the framework JS modules and the fonts in relative paths: nothing else to copy into your project. 

            
git clone https://github.com/jm-holland/illaweight.git
cd illaweight
npm install && npm run build:lib
CSS integration

With a bundler (Vite, esbuild...), import the package entry point. On a static page, a single link tag is enough: 

            
// main.js (from local sources / bundler)
// import "./illaWeightCss.css";

// static page (GitHub CDN)
<link rel="stylesheet"
      href="https://cdn.jsdelivr.net/gh/jm-holland/illaweight@main/illaWeightCss.min.css"/>
Interactions optionnelles

The modal, tabs and accordion are enabled by importing the interactions module (details in the JS docs): 

            
// import "./js/interactions.js";  (from local sources)
Dark mode

Add the attribute <html data-theme="light"> (the value "dark" enables the dark theme). The themeSwitch.js script handles the switch and persistence in localStorage: 

            
<html lang="en" data-theme="light">
Contributing from the sources

The git repository contains the Sass entry point and this documentation site:

Repository structure
            
git clone https://github.com/jm-holland/illaweight.git
cd illaweight
npm install && npm run build:lib

src/sass/main.scss      <- entry point (normalize, base, utilities, grid, layout)
src/sass/base/          <- typography, grid, responsive utilities
src/sass/components/    <- buttons, card, form, table, modal, tabs, accordion...
src/sass/layout/        <- navigation, footer, layout, normalize
js/                     <- scripts (burger menu, dark mode, alert, modal, tabs, accordion...)

Navigation bar

The navigation bar is the first component of the framework: brand, flat links, drop-down submenus (hover or pinned click), dark mode switch and responsive burger menu. See the real bar at the top of each page. Structural HTML code: 

        
/** === Navigation bar === */
<nav class="navigation" aria-label="Navigation">
  <div class="brand">
    <a href="/" title="Go to the home page">
      <img src="/image.png" alt="brand logo" />
    </a>
  </div>
  /** Burger menu */
  <input class="menu-hamburger" type="checkbox" id="menu-hamburger" aria-label="Open the menu"/>
  <label class="menu-icon" for="menu-hamburger">
    <span class="hamburger-icon" aria-hidden="true"></span>
  </label>
  /** Main menu */
  <ul class="menu">
    <li><a href="#typography">Typography</a></li>
    <li><a href="#blockquote">Blockquote</a></li>
    <li><a href="#buttons">Buttons</a></li>
    <li>
      <a href="#" aria-label="submenu">Javascript</a>
        <ul>
          <li><a href="#darkMode">Dark mode</a></li>
        </ul>
    <li>    
    /** Dark mode switch */
      <input type="checkbox" class="checkbox" id="themeSwitch" aria-label="Dark mode"/>
        <label for="themeSwitch" class="checkbox-label">
          <span class="moon" title="Dark">☽</span>

        </label>
      <script type="module" src="/js/themeSwitch.js"></script>
    </li>
  </ul>
</nav>

Spacing

illaWeight CSS offers a wide set of responsive margin and padding utility classes, in shorthand notation, to adjust an element's spacing.
Margins and padding

Assign responsive margin or padding values to an element, or to a single side of it, using the shorthand classes. Each property, all properties at once and the vertical and horizontal axes are covered. The classes build on a default Sass map ranging from 1em to 7em.

Notation

  • m- for classes that define the margin.
  • p- for classes that define the padding.
  • mt- / pt- for the top margin or padding.
  • mb- / pb- for the bottom margin or padding.
  • ml- / pl- for the left margin or padding.
  • mr- / pr- for the right margin or padding.

The size ranges from 1 to 7. Mobile-first responsive variants exist per breakpoint: .mt-md-3, .px-sm-2, .my-lg-1…

Examples:

            
.mt-1{
  margin-top : 1em;
}
.pl-3{
  padding-left:3em;
}

Colors & accessibility

Palette compliant with WCAG 2.1 AA: text ≥ 4.5:1, components ≥ 3:1, verified by automated audit in light and dark. Two families of variables:

  • “Text” shades — themed (dark in light, light in dark): --color-primary, --color-success, --color-danger, --color-error, --color-link and derivatives. The -focus suffix means hover and focus: darker in light, lighter in dark.
  • Constant solids — backgrounds with white text guaranteed ≥ 4.5:1 in any theme: --color-primary-solid, --color-success-solid, --color-warning-solid, --color-error-solid, --color-muted-solid, --color-secondary.

Accessibility

The framework automatically applies the WCAG 2.1 AA criteria: audited palette (colors and contrasts), visible keyboard focus (:focus-visible), touch targets ≥ 24px, animation disabled when prefers-reduced-motion.
