Why illaWeight?

Minimalist

A single bundle: normalize, typography, grid, components and utilities in one file.

Dark mode

A data-theme attribute on an element (whole page or local panel) and everything switches cleanly.

Responsive

12-column mobile-first grid + mixed col-sm/md/lg variants + spacing and display utilities.

Interactive

Modal, tabs and accordion via data-attributes: no JS framework, no dependency.

Alive, not a mockup

Everything below is rendered purely with the framework's classes.

Get started in one minute

A link tag via CDN, or npm install — because everything (fonts, icons, JS modules) works together. Enable dark mode with an attribute.

terminal 
# no install:
# a single tag is enough
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/jm-holland/illaweight@main/illaWeightCss.min.css"/>

# or from git:
git clone https://github.com/jm-holland/illaweight.git
cd illaweight
npm install && npm run build:lib
main.js 
// framework styles (from the repository sources)
// import "./illaWeightCss.css";

// optional interactions
// import "./js/interactions.js";
