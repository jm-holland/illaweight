Why illaWeight ?

Minimaliste

Un seul fichier CSS de ~50 kB (9.8 kB gzip) : normalize, typo, grille, composants et utilitaires.

Dark Mode ready

Un simple attribut data-theme sur <html> et le commutateur themeSwitch.js avec persistance.

Grille responsive

12 colonnes mobile-first + utilitaires col-sm/md/lg-*, spacing et display responsive.

Composants interactifs

Modal, tabs, accordion via une API data-attributes, sans dépendance JS.
