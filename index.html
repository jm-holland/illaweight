Pourquoi illaWeight ?

Minimaliste

Un bundle unique : normalize, typographie, grille, composants et utilitaires dans un seul fichier.

Mode sombre

Un attribut data-theme sur un élément (page entière ou panneau local) et tout bascule proprement.

Responsive

Grille 12 colonnes mobile-first + variantes mixtes col-sm/md/lg + utilitaires d'espacement et d'affichage.

Interactif

Modale, onglets et accordéon par data-attributes : aucun framework JS, aucune dépendance.

Vivant, pas une maquette

Tout ce qui suit est rendu uniquement par les classes du framework.

Démarrer en une minute

Une balise link via CDN, ou npm install — parce que tout (polices, icônes, modules JS) travaille ensemble. Activez le mode sombre avec un attribut.

terminal 
# sans installation :
# une seule balise suffit
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/jm-holland/illaweight@main/illaWeightCss.min.css"/>

# ou depuis git :
git clone https://github.com/jm-holland/illaweight.git
cd illaweight
npm install && npm run build:lib
main.js 
// styles du framework (depuis les sources du dépôt)
// import "./illaWeightCss.css";

// interactions optionnelles
// import "./js/interactions.js";
